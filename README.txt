# 非遗进大众-前端

本仓库存放非遗进大众的前端源代码

在线体验: https://haojiezhe12345.top:8092/

## 开发环境

[Node.js](https://nodejs.org/)  
[VSCode](https://code.visualstudio.com/) + [Vue](https://marketplace.visualstudio.com/items?itemName=Vue.volar)

## 设置开发环境

```sh
npm install
```

## 运行开发环境

```sh
npm run dev
```

## 为生产环境编译

```sh
npm run build
```
